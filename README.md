# Torque Quiz

Base inicial em Vite + React para um x1 de perguntas com tema de engenharia mecânica.

## Como rodar

```bash
npm install
npm run dev
```

## O que já existe

- Tela inicial com CTA verde para buscar partida.
- Navbar superior com navegação para páginas futuras.
- Área de perfil no topo.
- Espaços prontos para Partidas, Ranking e Perfil.
